# 일이 없어도 열려 있는 회사 사무실

Home 맨 위에 메인 에이전트의 사무실을 바로 표시한다. 프로젝트·지시·작업을 만들 필요가 없다. 기존 **부서와 직원** 목록과 각 프로젝트 작업실은 그대로 유지한다.

## 회사와 부서를 나눈 이유

프로젝트를 회사의 부서로 보는 관점을 유지했다. 메인은 회사 사무실에 있고, 부서 직원들은 각 부서의 작업실에 있다. Home에서 사무실을 바로 볼 수 있고, 부서 이름의 **사무실 보기**를 한 번 누르면 해당 직원들을 만난다. 회사 전체 직원을 하나의 큰 방에 중복 배치하지 않았다.

## 이번 후속 수정과 이유

회사 사무실만 2D로 고정했던 결정을 되돌렸다. 2026-10-28에 2D 사무실의 모습과 어색한 착석을 거부하고 실시간 3D로 다시 만든 방향을 따라야 한다. 2026-10-29에 정한 대로, 직원이 생길 때 그 직원의 책상과 캐릭터를 만든다. 메인 한 명 주위에 빈 책상 열두 개를 미리 놓지 않는다.

회사와 부서는 `OfficeScene`에서 같은 `Studio3D`를 사용한다. 기존 스튜디오의 `useStudio3D` 판정을 `lib/useStudio3D.ts`로 옮겨 공유했다. 새 판정을 따로 만들지 않았다.

| 조건 | 회사와 부서의 장면 |
|---|---|
| WebGL2를 사용할 수 없음 | 2D 대체 화면 |
| `studio3d=0` | 2D 대체 화면 |
| 웹 화면이 760px 이하이고 `studio3d=1`이 아님 | 2D 대체 화면 |
| 나머지 WebGL2 사용 가능 환경 | 3D |

따라서 기본 브라우저 화면은 1440px에서 3D, 390px에서 2D다. 데스크톱 분기는 좁은 폭에서도 3D를 쓴다. `studio3d=1`도 WebGL2가 없으면 2D로 돌아간다. 부서의 기존 선택 기준과 배치, 캐릭터, 업무 동작은 유지했다.

## 사람과 좌석

- `snapshot.members`의 삭제되지 않은 `isMain` 멤버를 사용한다. `snapshot.seat.holder`가 있을 때만 인물을 배치한다. 서버 실행 CLI와 외부 에이전트의 보유 방식은 장면 바로 위에 표시한다. 외부 에이전트의 업무 카드에는 외부에서 AI 설정을 관리한다고 표시한다.
- 3D 메인도 부서 직원과 같은 캐릭터 키트와 멤버별 책상 생성을 사용한다. 이름표와 가리키기·누르기로 여는 업무 카드, 팀원 상세 연결도 공유한다. 외부 보유자의 좌석 정보를 3D 카드에도 전달한다.
- 자리가 비어 있으면 방만 남기고 메인 캐릭터와 개인 책상을 만들지 않는다. **메인 자리가 비어 있습니다**라는 안내를 표시한다. 공용 회의 테이블과 소파는 방의 가구로 유지하며, 아래 메인 직원 정보도 계속 확인할 수 있다.
- 메인은 2D와 3D 모두 쉬는 동안 자기 책상 의자를 쓴다. 부서의 유휴 직원은 기존 소파 또는 자기 의자를 쓴다. 시간에 따라 서거나 돌아다니는 동작을 추가하지 않았다.
- 회사 2D 대체 화면도 메인이 있으면 책상·의자·칸막이를 각각 하나만 놓는다. 빈 자리에서는 셋 다 없다. 부서의 2D 배치는 그대로 유지한다.
- 이름표·포인터·터치·키보드 업무 카드와 **자세히 보기**는 기존 구현을 공유한다. 상세 패널도 기존 `MemberPanel`을 연다.

## 보지 않는 장면은 해제한다

회사와 부서 모두 `OfficeViewport`를 거친다. 페이지가 숨겨지거나 장면이 화면 밖으로 나가면 내부 장면을 해제한다. 다른 화면으로 이동할 때도 기존 화면 분기에 따라 해제된다. 자리는 같은 크기의 빈 영역으로 남겨 스크롤 위치가 튀지 않게 했다.

3D 사무실은 입장·착석·카메라 이동을 마친 뒤 전원 유휴·동작 줄이기·긴급 정지 상태에서 입력이나 화면 크기, 전달된 상태가 바뀔 때만 그린다. 회사 장면도 같은 정책을 따른다. 2D 대체 화면도 유휴 상태에서 1초마다 다시 그리던 처리를 멈추고, 상태·크기·동작 줄이기 설정이 바뀔 때 갱신한다. 전환 중인 착석 동작은 마친다.

동작 줄이기에서는 착석한 인물을 정지 상태로 보여준다. 긴급 정지는 실행을 재개하지 않으며 기존 안내를 유지한다. 390px에서도 2D 긴급 정지 안내가 잘리지 않게 줄바꿈한다.

팀원 상세가 열리면 회사와 부서 장면을 해제한다. Home에도 상세 열림 상태를 전달한다. 사무실에서 여는 상세는 기존 2D 초상화를 사용한다. 회사 사무실과 부서 사무실은 서로 다른 화면에 있으므로 동시에 장면을 만들지 않는다. 데스크톱에서 별도 초상화 WebGL 장면이 늦게 생성되거나 사무실과 겹치는 것도 막는다. 브라우저와 데스크톱은 같은 화면 컴포넌트를 사용한다.

## 개발용 재현

개발 서버의 쿼리 매개변수다. 실제 서버와 에이전트를 시작하지 않는다. 원격 배포 빌드에서는 개발용 매개변수와 가짜 브리지가 제거된다.

| 매개변수 | 화면 |
|---|---|
| `officeState=no-project` | 프로젝트·지시·작업 없음, 메인 한 명 |
| `officeState=empty-seat` | 프로젝트 없음, 메인 자리 비어 있음 |
| `officeState=idle` | 한 부서, 메인과 직원 모두 유휴 |
| `officeState=busy` | 기존 혼합 업무 상태의 부서 |
| `officeState=emergency` | 긴급 정지 상태 |
| `fakeMode=server&fakeSetup=ready` | 서버 연결 브라우저와 같은 화면 분기 |
| `fakeDesktop=1&fakeMode=desktop` | 데스크톱 브리지 화면 분기 |
| `fakeAgents=connected` | 외부 에이전트가 메인 자리 보유 |
| `studio3d=0` / `1` | 회사와 부서의 2D / WebGL2 사용 가능 시 3D |

예: `http://127.0.0.1:5196/?officeState=no-project&fakeMode=server&fakeSetup=ready`. 첫 화면 자체가 회사 사무실이다.

## 검사와 캡처

`components/always-office.test.ts`는 프로젝트 없는 Home, 메인 인물과 상세 연결, 빈 좌석, 외부 에이전트 표기, 2D와 3D에서 1시간 동안의 메인 착석, 숨김·상세 상태의 미생성, 공유 렌더러 선택과 유휴 그리기 정책을 검사한다. 회사 대체 화면의 책상·의자·칸막이는 인원과 수가 같아야 한다. 기존 `studio/idle-seating.test.ts`도 부서 인원의 장기 착석을 검사한다.

`components/web-stage8.test.ts`의 URL 읽기 허용 경로는 옮긴 공통 모듈로 바꿨다. DOM이 없는 해당 테스트에서는 3D 기능 판정만 대체한다. 실제 판정은 별도 규칙 테스트와 headless 브라우저에서 검증한다.

`tools/check-always-office.mjs`는 포트 5196의 Vite 개발 서버와 headless 브라우저 하나만 시작하고 종료한다. Vite 캐시와 브라우저 프로필은 시스템 임시 폴더를 사용한다. 브라우저·데스크톱 화면 분기, 1440px·390px, 2D·3D, 동작 줄이기·긴급 정지를 확인한다. 실제 이름표의 크기·경계·겹침, 착석 상태, 개인 책상과 캐릭터 수, 외부 보유자의 카드, 상세 패널, 숨김·화면 밖 이동 후 장면 해제와 유휴 그리기 중단을 검사한다. WebGL 컨텍스트 생성과 해제를 추적해 동시에 하나만 존재하는지도 확인한다.

화면 조작 검사는 높이 1000px로 한다. 390px 화면과 긴급 정지 화면의 캡처를 찍을 때만 높이를 1600px로 늘린다. 고정 안내와 명령창이 사무실 제목이나 설명을 덮지 않게 하려는 조정이며, 화면 폭과 렌더러 판정은 바꾸지 않는다. 실제 데스크톱 앱이나 운영 서버는 실행하지 않는다.

제공된 CPU 실행기 경로를 `OFFICE_VITEST_WRAPPER`에 지정해 아래 도구를 순서대로 실행한다.

```sh
bash "$OFFICE_VITEST_WRAPPER" -- npx tsc --noEmit -p tsconfig.web.json
node src/renderer/tools/check-contract.mjs
bash "$OFFICE_VITEST_WRAPPER" run --config src/renderer/tools/vitest.config.ts
bash "$OFFICE_VITEST_WRAPPER" -- npm run build:web
bash "$OFFICE_VITEST_WRAPPER" -- node src/renderer/tools/check-always-office.mjs
bash "$OFFICE_VITEST_WRAPPER" -- node src/renderer/tools/mutation-always-office.mjs
```

캡처와 검사 결과는 이 폴더에 저장한다. 공유 계약을 추가하거나 수정할 필요는 없었다. 기존 스냅샷의 멤버와 메인 좌석 정보만 사용한다.

## 검증 결과

타입 검사와 계약 검사, 렌더러 39개 파일의 525개 테스트, 서버용 웹 빌드가 통과했다. [변이 결과](mutation-results.json)의 30개 변이를 모두 검출했다. 3D 연결을 끊거나 메인의 책상·캐릭터를 누락하는 경우, 빈 책상·칸막이를 미리 배치하는 경우, 잘못된 환경 판정과 외부 보유자 카드, 숨김·유휴 정책 회귀를 포함한다.

각 브라우저 검사 경로의 정상 상태가 통과한 뒤 변이를 적용한다. 검증 실패로 잡힌 변이만 검출로 인정하며, 시간 초과나 구문 오류는 검출로 세지 않는다. 3D 그리기 정책은 실제 WebGL 호출로, 2D 그리기 정책은 SVG 변경으로 검사한다. 소스는 변이마다 원래 내용으로 복원한다.

[브라우저 검사 결과](browser-check.json)의 42개 조합도 모두 통과했다. 1440px·390px의 메인 전용·빈 자리·유휴 부서·바쁜 부서, 데스크톱 분기, 동작 줄이기, 긴급 정지, 외부 메인 보유자, 쿼리 강제 선택과 WebGL2 불가 환경을 포함한다. 이번 결과에 대응하는 캡처 42장을 직접 검토했다. 방과 메인의 자기 책상 착석, 이름표를 확인했고, 빈 자리에는 개인 책상이 없었다. 숨김과 화면 밖 이동, 상세 패널, 유휴 그리기 중단 검사도 통과했다. 동시 WebGL 컨텍스트의 최댓값은 1이었다. 포트 5196 개발 서버와 headless 브라우저는 종료했다.

이번에 추가한 소스는 `src/renderer/src/components/OfficeScene.tsx`와 `src/renderer/src/lib/useStudio3D.ts`다. 이전 라운드의 뷰포트·테스트·가짜 데이터·검사 도구 위에 이어서 구현했으며, 기존 소스 삭제는 없다. 이 폴더의 README·JSON 결과·PNG 캡처를 갱신했다. PNG는 저장소의 기존 ignore 규칙 대상이다. 소스나 이미지의 강제 추가, 커밋은 하지 않았다.

실제 운영 서버와 네이티브 데스크톱 앱은 이번 실행 금지 조건에 따라 시작하지 않았다. 대신 가짜 브리지의 서버·데스크톱 분기를 headless 앱 페이지로 검사했다.

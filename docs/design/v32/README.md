## 계측

- `cpu.json`: 12명 업무 중 메인 스레드 점유율과 초당 레이아웃 수
- `plate-audit.json`: 15개 장면 표본에서 보이는 이름표와 인물의 대응, 타인 가림, 거리
- `cycle-plate-audit.json`: 55초 동안 멈춘 인물의 이름표 이동
- `joint-audit.json`: 56초 동안 연속 3359프레임에서 관절별 회전 변화
- `width-audit.json`: 1100, 1920, 긴급 정지 화면의 폭·넘침·이름표 위치
- `palette-gate.txt`, `palette-audit.json`: 팔레트 게이트와 사무실 색도·색상 거리
- `screen-audit.json`, `font-audit.json`: 화면 문구, 글씨 크기·대비와 한글 글꼴
- `mutation-check.json`: 의도적으로 착석·업무 중 왕복·긴급 재개·좌석 회피·휴식 위치·검수 인계·이름표 폭 문제 일곱 가지를 되살렸을 때 해당 테스트가 실패한 기록. 검사 뒤 원본 코드를 복원했다.

최종 측정에서 12명 업무 중 메인 스레드 점유율은 0.056, 레이아웃은 초당 24.5회였다. 15개 장면에서 보이는 이름표 149개 모두 가장 가까운 몸통이 자기 주인이었고, 타인 가림은 0%, 주인까지 최대 거리는 55.65단위였다. 55초 순환에서 정지한 인물의 이름표는 최대 5.45단위 움직였다. 자세 전환의 연속 프레임 최대 회전은 25°였다. 웹 빌드 파일 전체는 952,307바이트였다.

## 남은 색상 제한

팔레트 게이트는 s01–s08과 s04 `--room`에서 통과한다. 사무실 픽셀의 21.33%가 C* 15 이상이고 여러 색상 계열에 분포한다. 다만 금지 기준색 세 개와 ΔE76 10 미만인 픽셀이 각각 0.049%, 0.060%, 0.053% 남아 있다. “해당 픽셀 0개” 조건은 아직 충족하지 못했다.

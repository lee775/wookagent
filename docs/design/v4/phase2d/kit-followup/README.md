# Character kit follow-up: 2x review

[24-member lineup](lineup-24-2x.png) | [Sofa conversation](sofa-talk-2x.png) | [Actual meeting table](meeting-table-2x.png)

The 24 full-resolution pages cover all 864 combinations: nine garments (including the producer coat), twelve hairstyles, headphones on/off, and four seated contexts. Each character render is 384 x 440 pixels for a 192 x 220 logical cell (2x). Furniture is omitted from the matrix so it cannot hide the hem. The actual studio close-ups above show furniture context.

Meeting uses the runtime `sit_think` pose. Other poses are `sit_type`, `sofa_talk`, and `sit_lean_back`. Five hairstyles (1, 3, 5, 10, 11) use ear cups without a band. All other styles use their fitted curved strap.

# 기획서 v0.5 → v0.6 변경 목록

2026-10-29 · 대표 검토용 · 설계 근거는 같은 폴더의 `server-design.md`(10-29 개정판)

이 문서에는 바뀌는 요구사항만 모았습니다. 바뀌지 않은 요구사항은 적지 않았습니다. 표마다 v0.5의 요지, v0.6에서 바뀌는 글, 까닭을 적었습니다. 까닭의 D1–D7은 0장의 결정을 가리킵니다.

## 요약

- 요구사항 ID 기준으로 **바뀜 62건, 삭제 1건, 새로 55건**입니다.

  - 삭제: CTL-05(대표 직접 메시지)
  - 새로: 대표 권한 OWN 5건, 메인 자리 SEAT 8건, 메인 일지 JNL 3건, 서버 SRV 8건, PC 조작 PC 8건, AUTH 3건, AGT·SEC·ROLE·UI 5건, 완료 기준 AC-51–65 15건
